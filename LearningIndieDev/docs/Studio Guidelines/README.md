# Studio Guidelines

This directory contains durable, studio-level practices that apply across game design, engineering, experimentation, automation, and AI-assisted workflows.

## Guideline conventions

- Each guideline receives a stable ID and version.
- Guidelines describe the default process, not a one-off task.
- Exceptions should be recorded in the relevant task, report, or decision record.
- Changes to a guideline should update its version and revision notes.
