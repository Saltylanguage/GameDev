# EX-011 — Cross-biome, cross-species transfer

**Status:** Executed; narrow finding accepted on 2026-09-17

EX-011 tests whether one accepted Forest Edge/Hare direction survives a move to
Open Range/Deer. The combined movement-and-crowding intervention increased
final Deer population in all 25 paired runs across development and held-out
panels. Josh accepted this as bounded evidence for the tested ordered
combination only; it does not approve individual-upgrade effects, player fun,
production balance, or generalized transfer. See [HUMAN_DECISION.md](HUMAN_DECISION.md)
for the recorded decision and [REPORT.md](REPORT.md) for the measured result.
