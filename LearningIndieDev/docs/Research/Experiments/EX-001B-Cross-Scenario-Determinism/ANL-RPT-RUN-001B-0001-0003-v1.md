## Executive summary

ForestEdge, OpenRange, Wetland, and BaselineParity each reproduced exactly across two current schema-4 runs over seeds `10100`–`10119`. The scenarios use different ruleset fingerprints, player species, rosters, and grid sizes, yet each repeated pair matched its complete machine-readable run payload and final
summary.

This supports an engine-level reproducibility statement across the four tested authored scenarios. The result does not imply that ecological findings transfer between scenarios or that arbitrary cellular automata are deterministic.

## Findings

### 1. Reproducibility is supported across four authored scenarios

**Status:** Supported within tested configurations  
**Confidence:** High within the tested scenario configurations

All 80 completed scenario-seed executions matched their paired repetitions after
generated metadata was excluded. The observed ruleset fingerprints were stable
within each scenario:

- ForestEdge: `c794841a72be34c241c7f811b848fe540914e5a8a9f55f5ee6406ae44f093fc4`
- OpenRange: `d7695716705d329a4a5b70e69996227d00d3197ccda1657045bd9d84369d59ef`
- Wetland: `82180c395409908f87c1c21ee817c0a305a81f9e45e7b252ba4cb50ec37fcd64`
- BaselineParity: `8e15ed2b7bb31ec503944a2df9f4bcb7a16f4d851d141529312324fb90a5ca3e`

### 2. Scenario diversity did not introduce a repeatability mismatch

The completed pairs cover one 32 x 32 scenario and three 32 x 20 scenarios, with
different species libraries and fingerprints. This is stronger evidence than
repeating ForestEdge alone, but it remains a sample of this engine and asset
library rather than proof about all cellular automata.

### 3. Setup and environment anomalies are distinct from simulation divergence

The invalid OpenRange player-species input was rejected before execution and was
corrected to `deer`. The first Wetland process returned a nonzero wrapper status
while still writing the expected complete report; its payload matched the second
run, but the environment status should be diagnosed before treating batch exit
codes as clean.

### 4. The relay constraint was handled without changing the evidence contract

The final BaselineParity repetition was run sequentially after confirming that no
Unity process was open. Unity exited and was verified absent afterward. No
parallel relay or generated-artifact editing was used.

## Scope and prohibited inference

The evidence supports only:

> For the four tested authored scenarios, identical scenario inputs, ruleset,
> player species, seed range, and run configuration reproduced identical
> machine-readable outcomes through the shared current-code engine.

It does not support claims that every cellular automaton is deterministic, that
one scenario's ecological outcome applies to another, or that the simulation is
correct, balanced, or player-validated.

## Recommendation

Proceed to EX-002 using the accepted ForestEdge baseline. The accepted result
supports only the bounded statement above; it does not authorize an
all-cellular-automata claim or transfer of ecological findings between
scenarios.
