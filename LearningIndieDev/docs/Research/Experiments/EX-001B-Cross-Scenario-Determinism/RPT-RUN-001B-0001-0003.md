## Execution anomalies

- The initial OpenRange attempt used `herbivore`, which is not defined by that
  scenario. Unity rejected the input before simulation; no report was produced.
  The valid pair uses the authored `deer` species.
- The first Wetland batch returned a nonzero wrapper status despite writing a
  complete report and log with the expected `Wrote 20 seeded cellular simulation
  runs` message. The report payload matched its repetition; the wrapper/license
  status remains an environment anomaly and is preserved for review.
- BaselineParity was completed in one final sequential Unity batch launch after
  confirming no Unity process was open. The process exited and was verified absent
  afterward.
