# Research

This directory contains bounded research programs and experiment briefs that
may influence product direction, tools, or studio practice.

Research documents are not automatically approved implementation work. Each
program must identify its question, evidence protocol, decision owner, and
promotion gate before it becomes a production commitment.

## Canonical program document

Use the [AI-Assisted Ecology Laboratory Research Plan](AI_ASSISTED_ECOLOGY_LAB_RESEARCH_PLAN.md)
as the single source of truth for the current thesis, protocol, prediction
contract, human-decision rules, experiment portfolio, and roadmap. Supporting
documents should link back here and may provide detail or evidence, but should
not redefine the program.
